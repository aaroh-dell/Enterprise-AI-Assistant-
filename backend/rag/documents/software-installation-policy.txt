EnterpriseCorp Software Installation Policy
To maintain system stability and prevent the introduction of malware, employees are prohibited from downloading or installing unauthorized software on EnterpriseCorp hardware. All endpoints operate with standard user privileges, meaning administrative rights required for software installation are locked. A pre-approved catalog of productivity, development, and design applications is available in the EnterpriseCorp Self-Service Software Center. Employees may install any application from this catalog without additional approval. For software not listed in the catalog, employees must submit a Software Request Ticket to the IT Service Desk. The request must include the business justification, the specific software version, and the licensing cost. IT Security requires up to 5 business days to evaluate the requested software for vulnerabilities, compliance with data privacy regulations, and system compatibility. If approved, an IT technician will remotely deploy the software to the user device. Employees attempting to bypass installation restrictions using portable executable files or unverified browser extensions will be flagged by endpoint detection systems, resulting in the immediate quarantine of the device and mandatory security retraining for the user.
